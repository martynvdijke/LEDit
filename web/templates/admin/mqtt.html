Per-device topics: ledit/device/<id>/brightness/set (0–100), ledit/device/<id>/select/set (source:<type>:<id>, playlist:<id>, scene:<id>), ledit/device/<id>/message/set (≤255 chars), plus the existing paused/set and next/set. Accepted commands publish retained state on the matching /state topic; rejected or malformed commands are ignored. Broker ACLs are the only authority for these commands.
